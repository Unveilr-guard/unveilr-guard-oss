Unveilr Guard is released under **AGPL-3.0-only**. That licence permits
commercial use, including inside a business, without payment or permission.

**The AGPL does not prohibit commercial use.** It is not a "non-commercial"
licence, and this project is not "free for non-commercial use only".

## When you may want a separate commercial licence

The AGPL's obligations — in particular §13, which extends source-availability to
users interacting with the software over a network — can be incompatible with
some distribution models. A separate commercial licence may suit you if you want
to:

- embed Unveilr Guard in a proprietary product you distribute;
- offer it as part of a hosted service without meeting §13;
- combine it with proprietary code in a way that would otherwise create a
  combined work under the AGPL.

If you simply run Unveilr Guard, modify it for internal use, or use it in CI,
**the AGPL is sufficient and no commercial licence is required**.
